# Architectural references

No source code from these projects is copied in this initial implementation.
Their public architectures informed Runlit's design:

- `sodiumsun/agenttrail` — local observation and file-activity model (MIT).
- `VladislavTsytrikov/tmuxpad` — process and terminal-pattern fallback (MIT).
- `justinchuby/flightdeck` — normalized provider event concepts (MIT).
- `SirAllap/agentglass` — local session discovery and deduplication (MIT).
- `handsome-rich/claude-buddy` — floating status-window interaction reference;
  no code reused because a license was not confirmed during planning.
